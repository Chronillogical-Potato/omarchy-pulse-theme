# Agent bell

A lantern for each of your AI agents (Claude Code, Codex, OpenCode, Gemini...), coloured by its state: working,
waiting for you, done, failed. By Marco Porro, MIT.

**Actions**: an agent starts waiting for you → a bell appears, rings and chimes; click it, or answer the agent, and it
goes away · an agent fails → lightning · an agent finishes → a shooting star with how many are still working.
